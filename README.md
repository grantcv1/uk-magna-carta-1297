# Magna Carta (1297) in Akoma Ntoso

Magna Carta (1297), 25 Edw. 1 cc. 1, 9, 29, the version of the charter that remains on the statute book of England and Wales. This is the text as published on legislation.gov.uk, in Akoma Ntoso XML, with a CSS stylesheet that renders it. It was generated by Claude for Grant Vergottini.

## Files

| File | Purpose |
| --- | --- |
| `magna-carta-1297.xml` | The Akoma Ntoso document |
| `magna-carta-1297.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Repeals:** Repealed chapters are `<chapter status="removed">`, and each carries the legislation.gov.uk repeal note as its text. The same repeals are recorded as `<textualMod type="repeal">` in `<passiveModifications>`. Chapters that remain have `class="inForce"`.
- **Grouped chapters:** Numbers such as II–VI, and notes such as "Cc. 11, 12", follow the source. Chapters XII and XXXIV have no entry of their own there.
- **Closing text:** The source has an unnumbered group after XXXVI–XXXVII. It is an `<hcontainer name="wrapper">`.
- **Variant readings:** Words the source marks as variants are in `<span class="variant">`, followed by a `<noteRef>` to the note in `<conclusions>`.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither.

## Text

The English is the traditional translation used on legislation.gov.uk, retrieved on November 3, 2026, and is unchanged. The source also shows the Latin original as images, which are not included here. The source's extent is England and Wales.

legislation.gov.uk publishes its own Akoma Ntoso for this statute. This document is a separate edition in the house style used across this archive, built from the site's XML data.

The repealed chapters are not reproduced, because the source omits them. Their dots are kept in `<omissis>`.
